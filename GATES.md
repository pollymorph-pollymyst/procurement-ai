# Проверки готовности

Каждый пункт проверяется командой. Всё зелёное — можно отдавать.

| # | Что должно быть верно | Как проверить | Ожидаем |
|---|---|---|---|
| 1 | Расчёт проходит от выгрузки до дашборда | `python -m procurement run --no-open` | «Готово. Заказать сейчас: …», код 0 |
| 2 | Заказы положительные и кратны шагу из истории | `pytest -q -k rounded` | passed |
| 3 | Низкая наценка, редкий спрос и «нужен поставщик» не попадают в заказ | `pytest -q -k low_markup` | passed |
| 4 | Заказы в пути не заказываются повторно | `pytest -q -k twice` | passed |
| 5 | Сомнительные заказы (просрочка > 60 дн.) не идут в запас | `pytest -q -k doubtful` | passed |
| 6 | Сезонный товар заказывается заранее (обогреватели к октябрю) | `pytest -q -k heaters` | passed |
| 7 | Прогноз точнее «среднего за год» на прошлом году | `pytest -q -k backtest` | passed |
| 8 | В комментарии нет чисел, которых нет в расчёте | `pytest -q -k number` | passed |
| 9 | На каждого поставщика есть Excel-файл заказа | `pytest -q -k export` | passed |
| 9a | Отправленный заказ считается в пути, второй раз не предлагается | `pytest -q -k sent` | passed |
| 9b | Праздники удлиняют срок, недовоз уменьшает ожидаемое | `pytest -q tests/test_holidays.py` | passed |
| 9c | Выгрузка из 1С (cp1251, `;`, xlsx, русские колонки) даёт тот же результат | `pytest -q tests/test_intake.py` | passed |
| 9d | Комментарий любого сервиса проходит проверку чисел, ключ не попадает в config | `pytest -q tests/test_writers.py` | passed |
| 9f | Неполная выгрузка останавливает обновление; отправленный заказ не прячет дефицит до прихода | `pytest -q -k "partial or sent"` | passed |
| 9g | Файл поставщику без внутренних колонок; дата выгрузки не из даты файла; выключатель не трогает daily.yml; «Что изменилось» объясняет отправленные | `pytest -q tests/test_uat_fixes.py` | passed |
| 9e | Первая настройка: проверка папки ничего не переносит, отметка «пройдена» сохраняется | `pytest -q tests/test_setup.py` | passed |
| 10 | Запуск двойным щелчком на чистой машине | удалить `.venv`, запустить «Обновить анализ.bat» | дашборд открылся |
| 11 | «Что изменилось» работает | `outputs/history/` содержит ≥ 2 снимков; вкладка показывает изменения | есть строки |
| 12 | Дашборд без ошибок на ПК и телефоне | открыть `docs/index.html` на 1440 и 390 px, светлая и тёмная тема | нет горизонтальной прокрутки, консоль пуста |
| 13 | Дизайн-проверка | `impeccable detect --json dashboard/index.html` | `[]` |

Все автоматические проверки сразу: `python -m pytest -q` (42 теста, ~45 с; нужен `pip install -r requirements-dev.txt`).
