# Обновить план закупок с комментарием

1. Запусти расчёт:
   ```bash
   PYTHONIOENCODING=utf-8 python -m procurement run --no-open
   ```
   Если команда упала с «ОШИБКА В ДАННЫХ» — перескажи пользователю ошибку простыми словами и остановись.

2. Прочитай `outputs/latest/facts.json` (факты расчёта и блок `changes` — что изменилось с прошлого запуска)
   и `prompts/analyst.md` (правила комментария).

3. Напиши комментарий строго по правилам из `prompts/analyst.md`. Главное:
   - каждое число — дословно из facts.json, ничего не пересчитывай сам;
   - простой русский, сначала действие;
   - если в `changes` есть изменения — одна фраза о них.

4. Сохрани в `outputs/commentary_override.json`:
   ```json
   {"as_of": "<meta.as_of из facts.json>",
    "comment": {"headline": "...", "summary": ["..."], "actions": ["..."], "warnings": ["..."],
                "source": "claude-code"}}
   ```

5. Вставь комментарий в дашборд без пересчёта:
   ```bash
   PYTHONIOENCODING=utf-8 python -m procurement comment
   ```
   Если напечатано «Внимание: комментарий отброшен: числа не из расчёта (…)» — исправь эти числа
   по facts.json и повтори шаги 4–5.

6. Ответь пользователю 3–5 строками: главное действие, сколько поставщиков и штук, что изменилось,
   путь к дашборду `docs/index.html` и к файлам заказов `docs/orders/`.
